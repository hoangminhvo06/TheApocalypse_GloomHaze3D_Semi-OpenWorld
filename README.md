# TheApocalypse_GloomHaze3D_Semi-OpenWorld
The Apocalypse_Gloom Haze_Semi Open World

Game 3D AA lấy bối cảnh ngày tận thế sinh tồn trong thế giới đổ nát. Game được thiết kế tập trung chủ yếu vào environment map thế giới mở và atmosphere nhằm tạo cảm giác hồi hộp, phiêu lưu cho người chơi.

Công nghệ:
Unity 6/ Universal Render Pipeline( URP )
C#, ShaderGraph, Shader, VFX
Phạm vi dự án:
Hệ thống gameplay trung bình
Animation nâng cao ( Blend Tree )
Đồ họa Terrain trung bình
Thế giới mở rộng lớn
Cốt truyện có chiều sâu
Tổ chức dự án:
Thành viên: 1 ( Tôi )
Vai trò: Solo Developer
Công việc:
Thiết kế hệ thống gameplay
Xây dựng map
Viết GDD lên ý tưởng phác thảo game
